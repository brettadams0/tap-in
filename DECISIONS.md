# Decisions

One line per open choice, with the reason. Newest at the bottom of each section. See PLAN.md §0 for longer context.

## Platform and stack

| #   | Decision                                                                                                     | Reason                                                                                                                          |
| --- | ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| D1  | Vite + React 19 SPA (not Next.js)                                                                            | Every screen is live socket state, so SSR adds weight and buys nothing. Static files on Vercel's edge.                          |
| D2  | Motion (`LazyMotion`) + CSS keyframes for animation                                                          | Layout and orchestration animations at about 15 KB gz, using only transform and opacity                                         |
| D3  | Raw Web Audio with an in-house synth + a few CC0 samples                                                     | Sample-accurate scheduling, and per-player variants cost no bytes. Tone.js is too heavy.                                        |
| D4  | Cloudflare Workers + Durable Objects (free plan) for the room server                                         | Free, stateful, one object per room, durable storage, alarms. Fly.io isn't free, and Render's free tier sleeps and loses state. |
| D5  | Durable Object location hint `enam`                                                                          | Players are in Ontario, so the object should run near Toronto                                                                   |
| D6  | Engine is host-agnostic (injected Clock / Scheduler / Storage)                                               | Pure tests, and the Node adapter gives fast integration tests                                                                   |
| D7  | Zod on the server only                                                                                       | Validates all input without adding it to the client bundle                                                                      |
| D8  | pnpm workspaces + Turborepo                                                                                  | Strict dependencies, cached CI                                                                                                  |
| D9  | Vercel Hobby, `tap-in-omega.vercel.app`                                                                      | Your free account. Non-commercial use is fine.                                                                                  |
| D10 | `patch` messages are diffs of each player's already-filtered view                                            | A patch can never leak more than a snapshot, and recovering from a version gap is simple                                        |
| D11 | Clock sync: median offset of the 3 lowest-RTT pings out of 5, refreshed every 30 s and on `visibilitychange` | Low-RTT samples have the least asymmetric error, and phones drift after sleeping                                                |
| D12 | `playAt` lead time 600 ms; cues up to 150 ms late play offset, later ones skip the sound                     | Absorbs Wi-Fi jitter while keeping sync                                                                                         |
| D13 | `Date.now()` in Workers only advances at I/O, which is acceptable                                            | `pong.serverTime` is stamped at message receipt, which is the instant sync needs                                                |

## Rules and interpretations

| #   | Decision                                                                                                                                                                                                                      | Reason                                                                                                     |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| R1  | No new players after Start. Only existing players get back in (rejoin token, or claiming a seat with host approval). The host can remove a player.                                                                            | Your call. Claiming keeps a player's history, and strangers can't barge in.                                |
| R2  | Prompt bank minimums count **per spice level** (60 Chill + 60 Spicy + 60 Unhinged…)                                                                                                                                           | Every level feels fresh and repeats are rare                                                               |
| R3  | Countdown: you can't tap twice in a row                                                                                                                                                                                       | Otherwise one player can count alone and nobody collides                                                   |
| R4  | Secret Word: 15 s per hint turn (ends on submit); the outsider is never first                                                                                                                                                 | 25 s for everyone is too short, and 25 s each drags. Going first blind isn't fun.                          |
| R5  | A connected non-submitter gets the worst outcome; a disconnected player abstains                                                                                                                                              | Otherwise ignoring the phone would be the best strategy                                                    |
| R6  | Fairness cap covers assigned drinks only (not "everyone drinks" or self-inflicted ones)                                                                                                                                       | Redirecting group or self-caused drinks makes no sense and could be gamed                                  |
| R7  | Capped player in a multi-drinker result: they're excused and the others still drink. If that leaves nobody, the next-worst drinks, or "lucky escape" when there's no ranking. Spin the Bottle never lands on a capped player. | The cap rule works with every game shape                                                                   |
| R8  | Rank It: drag + tap-in-order fallback                                                                                                                                                                                         | Tipsy thumbs, accessibility                                                                                |
| R9  | Two Truths: a player can reroll their fake fact if it's actually true for them                                                                                                                                                | Otherwise the round breaks on a fluke                                                                      |
| R10 | Names are always filtered; answers always block slurs; mild swearing is masked only at Chill                                                                                                                                  | Matches each spice level's intent                                                                          |
| R11 | Imposter is "caught" when they get more than half of the votes cast; the imposter votes too                                                                                                                                   | "Majority", read literally                                                                                 |
| R12 | Fake Answer "too close" = normalised similarity ≥ 0.75 or containment; identical fakes are merged                                                                                                                             | Stops near-copies of the real answer; duplicates would give the answer away                                |
| R13 | Spin the Bottle: 20 s Dare/Drink choice (a timeout counts as Drink), 20 s to perform, 10 s Done/Nope vote; the player drinks if Nope > Done                                                                                   | The spec doesn't give the flow                                                                             |
| R14 | Reaction Shotgun: about 30% of rounds have a fake-out. Under 90 ms, or received before `playAt - 50 ms`, counts as early.                                                                                                     | A fair mix, plus anti-cheat                                                                                |
| R15 | Session length is a time budget that never cuts a game short. Two Truths is capped at 3 spotlights on Short or with 7+ players.                                                                                               | Keeps the length predictable                                                                               |
| R16 | Fewer than 3 active players mid-game → "Waiting for players…" pause                                                                                                                                                           | The game needs 3 or more                                                                                   |
| R17 | Skip-prompt flags log only `{bankId, promptId}`                                                                                                                                                                               | No identifying data                                                                                        |
| R18 | Room codes: alphabet without I and O, filtered against a rude-word list                                                                                                                                                       | Spec: no ambiguous letters                                                                                 |
| R19 | e2e screenshots run with reduced motion, a fixed seed and scaled timers                                                                                                                                                       | Stable baselines                                                                                           |
| R20 | Priority order: readable > playable > fun. Screens have four zones, and decoration lives only in the margin zone during input phases.                                                                                         | Your direction: readability and playability come first                                                     |
| R21 | Cap builder: 16 colours that are exclusive per room, 8 patterns, 100 faces, 12 toppers, Shuffle; edits only in lobby or results                                                                                               | More self-expression, and a cap never changes while people are reading it                                  |
| R22 | Reactions come from fixed lists only: 8 fixed most-used emoji + Kind / Funny / **Glaze** (flirty) notes, with 4 random lines per tab from pools of 40+ and a 🔀 reshuffle; lines are spice-tagged                             | Your call: fresh options every time. Glaze = flirty, renamed. No free text, so nothing nasty can be typed. |
| R23 | Reactions can only be sent when the sender has time; delivery waits until the receiver is free and is dropped after 20 s                                                                                                      | Reactions must never cover important content or interrupt input                                            |
| R24 | Emoji reactions are shown to the whole room (they fly cap to cap); the words of a note are private to the recipient (others see 💌)                                                                                           | Social fun without public embarrassment                                                                    |
| R25 | Reaction rate limits: 1 per 3 s per sender, at most 4 per minute to the same person; per-player mute; host can turn reactions off for the room                                                                                | Stops spam and harassment                                                                                  |

## Phase 1 implementation

| #   | Decision                                                                                                                  | Reason                                                                                                                                                                             |
| --- | ------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| I1  | Reconnect tokens are stored as-is in Durable Object storage (not hashed) and compared in constant time                    | Storage is private to the object, and hashing with WebCrypto is async, which would break the engine's synchronous, race-free event handling. Tokens rotate when a seat is claimed. |
| I2  | One `RoomEngine`, two adapters: the Durable Object (prod) and Node `ws` (integration tests, e2e, local dev)               | Fast and reliable tests with real sockets. workerd tests still cover the DO adapter itself.                                                                                        |
| I3  | Timers are derived from state (disconnect times, claims, expiry) and armed on a single alarm, using future deadlines only | Survives hibernation and restarts, and avoids the re-fire loop a stale deadline caused in an early test                                                                            |
| I4  | Removing a player in the lobby deletes the seat; mid-game it marks them removed                                           | In the lobby there's no history to keep, and the name and colour are freed                                                                                                         |
| I5  | Seat claims auto-approve when nobody is connected to approve them                                                         | Otherwise a room where everyone lost their session would be stuck                                                                                                                  |
| I6  | Tiny in-house router (`/`, `/:code`, `/sync-test`) instead of React Router                                                | Three routes; saves bundle size                                                                                                                                                    |
| I7  | Lobby uses CSS keyframe animations; Motion comes in with phase 2's game animations                                        | Keeps the phase 1 bundle small (82 KB gz)                                                                                                                                          |
| I8  | Fonts come from Fontsource npm packages (bundled, Latin subset)                                                           | Self-hosted as the spec requires, cached with immutable hashes                                                                                                                     |
| I9  | The workerd test config aliases `obscenity` to its CJS entry                                                              | Its ESM wrapper re-exports a CJS default the test loader can't unwrap. The production esbuild bundle is unaffected (checked with `wrangler dev`).                                  |

## Phase 2 implementation

| #   | Decision                                                                                                                                           | Reason                                                                                                                       |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| G1  | Synced cues ride on the per-player view (`phaseAt`, `flashAt`, deadlines) instead of separate `schedule` messages                                  | The view is already filtered per player, so private cues (your Drink horn) stay private, and a reconnect restores them free  |
| G2  | Still CSS keyframes, not Motion (replaces I7's plan)                                                                                               | Every phase 2 animation is transform/opacity keyframes; the game chunk is 7 KB gz instead of about 22 KB                     |
| G3  | All sounds are synthesised at play time with Web Audio; no audio files yet                                                                         | Zero download, per-player notes and timbres for free; CC0 crowd samples can still be added in phase 6                        |
| G4  | Would You Rather: connected non-voters drink; a unanimous vote or a tie means nobody drinks                                                        | Applies R5 (ignoring the phone must never be safe); with no smaller side, nobody lost                                        |
| G5  | Reaction Shotgun: if anyone taps early, only the early tappers drink; otherwise the slowest (a connected non-tapper counts as slowest)             | The spec's "otherwise", plus R5                                                                                              |
| G6  | The flash time enters the view only within the 600 ms cue lead; the wait is never shorter than the lead                                            | Phones can schedule the flash in sync, but nobody can read it early                                                          |
| G7  | The Drink moment ends early once every connected drinker taps Done (it still holds at least 1.8 s)                                                 | Keeps the pace up without cutting the moment short                                                                           |
| G8  | The session also freezes ("waiting") when nobody is connected                                                                                      | If the room's Wi-Fi drops, rounds don't silently run out with everyone abstaining                                            |
| G9  | Content banks below their minimums are warnings until phase 5, then `--strict` makes them errors                                                   | Phase 2 ships starter banks (about 30 per spice level); the build-time validator already checks schema, duplicates and words |
| G10 | `TIME_SCALE` (Node adapter only) speeds up game timers for e2e and dev; presence, claim and expiry timers are never scaled; production is always 1 | Fast, realistic browser tests of the full loop                                                                               |
| G11 | Basic awards in phase 2: Most drinks, Fastest thumbs (average reaction), Cleanest record; the rest come in phase 6                                 | Results needed something to celebrate now                                                                                    |
| G12 | Settings still list all 11 games; games not built yet are tagged "Soon" and skipped by the rotation                                                | Settings stay stable across phases, and a host can't start with only unbuilt games (the server refuses)                      |

## Phase 3 implementation

| #   | Decision                                                                                                                                                      | Reason                                                                                                |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| H1  | Liar's Prompt has a fixed-length `show` step: answers land 1.4 s apart from a shared server time, each with a stamp in the answerer's voice                   | "Reveal one by one in sync": the timing rides on the view like every other synced moment (G1)         |
| H2  | The imposter keeps seeing their own question during the vote, next to the real one                                                                            | The spec shows everyone the real question at the vote; the imposter finding out there is the fun part |
| H3  | "Everyone except X" is its own Drink shape (`spared`): uncapped, no streaks, the escapee gets a GOT AWAY WITH IT screen and a private cheer                   | Follows R6; the escapee deserves a moment, and nobody else needs a Done button that isn't theirs      |
| H4  | Connected non-voters drink alongside a caught imposter or outsider, and in Two Truths and Fake Answer                                                         | R5: ignoring the phone must never be the safe play                                                    |
| H5  | Secret Word uses the same "more than half" catch rule as Liar's Prompt                                                                                        | One rule for both, R11                                                                                |
| H6  | Secret Word never blocks the outsider's hint, even when it's the word                                                                                         | A "too close" message would tell the outsider the word                                                |
| H7  | A hint gives the word away if it contains it, is a 4+ letter chunk of it, or is 80%+ similar; the outsider's guess counts at 80%+ similar                     | Catches plurals, typos and "melon" for "watermelon" without blocking honest hints                     |
| H8  | A caught outsider who never guesses drinks; a disconnected player's hint turn is skipped right away and shows 🤐                                              | Caught is caught; one dropped phone must not stall 4 others for 15 s                                  |
| H9  | Two Truths: setup runs once, at the start of round 1; only players who typed their facts get a spotlight, so the block can shrink (`plannedRounds`)           | Nobody gets spotlighted with nothing to show, and the header's "Round 1 of N" stays honest            |
| H10 | Two Truths: reroll only before locking in; no guesses at all means nobody drinks; the spotlight earns a liar point per person fooled                          | Locking in ends setup early, and an empty room must not punish the spotlight                          |
| H11 | Fake Answer: a fake is "too close" at 75%+ similarity or when every word of one is in the other; numbers only clash when they're the same number              | R12, but "1933" is a perfectly good fake for "1932"                                                   |
| H12 | Fake Answer: with no fakes there's nothing to vote on (nobody drinks); when nobody falls for a fake it's a "Sharp crowd" nobody-drinks                        | Both are designed outcomes, not lucky escapes                                                         |
| H13 | A minimal **Best liar** award ships now: people fooled + escapes as imposter or outsider                                                                      | The spec ties Master Liar to the end-screen awards; phase 6 polishes the full set                     |
| H14 | Profanity tiers: slurs and hate terms from the `obscenity` dataset (plus "rape") are refused at every level; other swearing is masked with asterisks at Chill | R10, with a fixed, reviewable list                                                                    |
| H15 | Typed limits: Liar's answers 30, Secret Word hints 20 (one word), guesses 30, Two Truths facts 60, Fake Answer fakes 40 characters                            | Short enough to read at arm's length, long enough to be funny                                         |
| H16 | A game's rejection ("Too close, try again.") shows right under the input, not as a toast                                                                      | It sits where the player is looking, and toasts can cover the status zone                             |
| H17 | `GameModule.rounds` and `estimateMs` now get the session length                                                                                               | Two Truths' spotlight cap on Short sessions (R15)                                                     |
| H18 | The engine refreshes the step deadline after every input                                                                                                      | Secret Word's next hint turn starts its own 15 s the moment a hint lands                              |
| H19 | Starter banks for the new games are 15–30 entries per spice level; every trivia answer is one I'm confident is true                                           | The validator warns until phase 5 fills the banks; a wrong "real" answer would ruin a round           |

## Phase 4 implementation

| #   | Decision                                                                                                                                         | Reason                                                                                |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------- |
| J1  | Rank It uses hand-rolled pointer-event drag plus tap-in-order, not Motion `Reorder`                                                              | Same feel on touch for four rows, and it keeps Motion out of the bundle (G2)          |
| J2  | Rank It distance is rounded to 2 decimals; ties for furthest all drink; perfect agreement is a "Great minds…" nobody-drinks                      | Floating-point noise must not pick a drinker; agreement isn't losing                  |
| J3  | Tap Race's 5 s window and Countdown's 600 ms collision window are never time-scaled; the 3-2-1 and round clocks are                              | Counts and collisions mean the same in e2e as at a party                              |
| J4  | Tap Race refuses counts above 100 (20/s × 5 s); a refused or missing count from a connected phone scores 0                                       | SPEC's cap, and R5                                                                    |
| J5  | Countdown: hitting the target waits for that tap's 600 ms window to close cleanly before it counts                                               | A last-moment collision must still reset the count                                    |
| J6  | Countdown colliders always drink (self-inflicted), even when the group later reaches the target                                                  | "Those players drink and the count resets"; our engine has one Drink moment per round |
| J7  | Spin the Bottle: only the Done/Nope vote ends early; the choice and the 20 s to perform always run their full time                               | A phone that locks mid-dare must not skip the dare or the choice                      |
| J8  | Spin the Bottle: a chosen player who is offline when the choice runs out sits it out (nobody drinks); online and silent counts as Drink          | Never penalise a disconnect (SPEC); idle is R13's "timeout counts as Drink"           |
| J9  | Spin the Bottle never lands on a capped player: the engine passes `capped` in `GameCtx`                                                          | R7                                                                                    |
| J10 | Fill in the Blank merges identical answers (shared votes); fewer than two answers skips the vote                                                 | Duplicates would give authorship away; one answer can't lose                          |
| J11 | All 11 games are ready; a host can now keep a single game on (was 2)                                                                             | Hosts can run one favourite, and tests can isolate a game                             |
| J12 | Dares and reaction notes have validator word lists (touching, contact info, filming, leaving, bodies, appearance)                                | SPEC §9 and DESIGN §12 safety rules, enforced at build time                           |
| J13 | Reactions: one `canReact(view, player)` rule in `@tap-in/shared/reactions`, used by the server to refuse and by the phone to show or queue       | Sending and receiving follow the same "has time" rule (R23)                           |
| J14 | Reaction rate limits are kept in memory per room (not persisted)                                                                                 | Reactions are never stored; a restart only resets a 3 s / 1 min window                |
| J15 | The reaction pools ship to the phone (a lazy 5.6 KB chunk); the server re-checks the note id and spice and sends the words only to the recipient | The phone must deal lines; the words stay private (R24)                               |
| J16 | The reaction lane sits in the page flow under the screen, and the screen gives up the lane's height                                              | It never covers the status or action zones, and nothing scrolls off                   |
| J17 | Mute and "Reactions off" are per phone (localStorage); the host's room switch stops sending for everyone                                         | Muting is personal; the room switch is the host's call                                |
